Dilwar Govey - مشروع أندرويد أولي يعمل دون اتصال

المحتويات:
- app/src/main/assets/index.html: واجهة التطبيق المحلية.
- MainActivity.java: غلاف Android WebView.
- لا توجد صلاحية إنترنت في AndroidManifest.xml.
- التخزين يتم محلياً على الجهاز عبر localStorage داخل WebView.
- .github/workflows/build-apk.yml: إعداد بناء APK تلقائياً عبر GitHub Actions.

بناء APK من الهاتف عبر البناء السحابي:
1) يلزم وجود حساب GitHub مسموح لك باستخدامه وفق شروط الخدمة؛ لا تشارك كلمة المرور أو رموز الدخول مع أي شخص.
2) أنشئ مستودعاً جديداً (Repository) وارفع محتويات هذا المجلد إليه، مع الحفاظ على المجلد المخفي .github.
3) افتح تبويب Actions في المستودع.
4) اختر "Build Dilwar Govey APK" ثم Run workflow، أو انتظر انتهاء البناء بعد رفع الملفات إلى فرع main.
5) عند نجاح البناء، افتح نتيجة التشغيل (workflow run)، وانزل إلى Artifacts، ثم نزّل Dilwar-Govey-debug-APK.
6) فك ملف ZIP الناتج على الهاتف ثم افتح app-debug.apk للتثبيت، إذا سمحت إعدادات Android بذلك.

مهم:
- هذا مشروع مصدر أولي، وليس APK جاهزاً الآن.
- لا أستطيع تشغيل حساب GitHub أو رفع المشروع نيابةً عنك من هذه المحادثة.
- APK الناتج من هذا المسار نسخة debug للتجربة، وليس ملف إصدار نهائي للنشر.
- للنشر على Google Play نحتاج إصداراً موقّعاً AAB، وسياسة خصوصية، واختبارات ومتطلبات المتجر.
- لا تضع أي كلمات مرور أو مفاتيح توقيع أو بيانات شخصية في المستودع.
